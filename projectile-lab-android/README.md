# Projectile Lab — Android

An offline, touch-friendly projectile-motion teaching simulator inspired by the learning mechanics of PhET's Projectile Motion simulation, but implemented as original UI/JavaScript rather than copying PhET branding/assets.

## Features
- Explore mode with adjustable launch angle, speed, height and target distance.
- Fire a projectile and try to hit the target.
- Objects: cannonball, pumpkin, football, golf ball.
- Earth, Moon and Mars gravity presets.
- Optional quadratic air resistance.
- Velocity and acceleration vectors.
- Ideal trajectory overlay and motion trail.
- Live range, maximum height, flight time, vx and vy.
- Guided demos: 45-degree range, horizontal/vertical independence, and air resistance.
- Challenge mode with randomly generated targets and scoring.
- Landscape-first, touch-friendly UI for secondary-school classrooms.

## Build

Use Android Studio or the GitHub Actions workflow. The project expects Android SDK 35 and Gradle 8.7+ / AGP 8.6.1.
